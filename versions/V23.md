## Version 23.3.1 — Dynamic Language Discovery, Search Filtering & Windows-Style Toast Feedback

- **Dynamic Language Pack Discovery**:
  - Automatically watches and subscribes to the `languages/` folder. When a new custom `.json` language pack is placed in `languages/`, it instantly appears in the language selection screen and settings modal without restarting the app.
  - Custom language files cleanly display title, key counts, and country/language codes.
- **Search Filtering for Large Language Catalogs (> 10 Languages)**:
  - When more than 10 languages or language packs are available, a clean search bar appears above the selection list.
  - Real-time search filters by language name, code (e.g. `DE`, `EN`, `IT`), subtitle, and filename.
  - Includes instant clear (`X`) button, result count, and empty state with reset button.
- **Windows 11-Style Bottom-Right Account Creation Toast**:
  - Moved the success notification upon account creation from the center screen overlay to a non-intrusive fixed toast notification anchored to the bottom-right corner.
  - Automatically dismisses after at most 10 seconds (with manual close button and smooth fade animation).
- **Full Quad-Lingual Localization**:
  - Localized strings in German, English, French, and Spanish for all new toast and search elements via `src/lib/i18n.ts`.

## Version 23.3.0 — Windows 11 Personalization Center, Live Blur & Unsaved Changes Guard

- **Windows 11-Style Personalization Sub-Tabs**: Redesigned the Personalization settings view into structured sub-categories mirroring Windows 11:
  - **Wallpaper & Blur**: Live interactive desktop preview showing current wallpaper, desktop icons, and active sample window, coupled with a real-time blur slider (0px to 30px with quick presets: Sharp, Soft, Medium, Strong), custom file upload, and curated preset wallpapers.
  - **Start Menu**: Custom background/header image upload for the Windows 11 Start menu with an independent blur slider for clear readability.
  - **Colors & Accent**: Picasso mode, Windows 11 taskbar themes (Acrylic Glass vs. Deep Dark), and curated accent color swatches with live button and badge previews.
  - **Fonts & Zoom**: Fluid font scaling slider (90% to 130%) with immediate zoom reset.
- **Unsaved Changes Confirmation Guard**: When closing the Settings window with modified settings, an interactive confirmation dialog prompts the user:
  - **Save**: Saves all changes immediately and closes the window.
  - **Don't Save**: Discards changes, reverts to previous state, and closes.
  - **Cancel**: Returns directly to the Settings editor without losing progress.
- **Persistent Fixed Bottom-Right Save Action**: Added a fixed-position save button and dirty state badge in the bottom-right corner of the Settings window, ensuring instant saving without needing to scroll.
- **Clean Start / Lock Screen Language Selector**: Removed unnecessary country flags from the start screen and lock screen language selectors, providing a minimal, elegant dropdown.
- **Full Quad-Lingual Coverage**: Added localized strings in DE, EN, FR, and ES for all new personalization sub-categories, blur levels, and unsaved dialog actions.

## Version 23.2.5 — Consolidated User Management & Profile Personalization in Settings

- **Consolidated Workspace Settings**: Removed the floating top-right person/gear overlay button from the desktop workspace, centralizing all account settings into **Settings > Users & Accounts**.
- **Unified Profile & Personalization Hub**: Users can now customize their profile display name, avatar photo, personalized desktop background wallpaper, auto-lock timeout, and change their own password directly within Settings.
- **Role-Based Tabs**: Administrators can seamlessly switch between "My Profile & Personalization", "User Management" (for creating, disabling, editing, or deleting accounts and temporary password resets), and "Security Policies" (lockout attempts, lockout duration, exponential backoff).
- **Windows-Style Start Menu Integration**: Clicking the user badge at the bottom of the Start menu opens Settings focused directly on the Users & Accounts section.
- **Comprehensive 4-Language Localization**: Added complete translations for all new user profile tabs and labels across German, English, French, and Spanish.

## Version 23.2.4 — Localization Alignment & Crisp Vector Flag Rendering

- **Rotated Translation Dictionary Fix**: Corrected cyclical translation assignment where German received French strings, English received Spanish, French received German, and Spanish received English for start menu power actions (`desktop.start_*`).
- **Windows Flag Emoji Degradation Fix**: Resolved the duplicate country code text issue on Windows (such as "DE DE" or "EN EN") caused by Windows Segoe UI Emoji lacking graphic country flag glyphs. Built-in crisp vector SVG flags are now displayed cleanly across all platforms.
- **Complete Language Parity**: Added missing `status.storage_tooltip` localization in French and Spanish, ensuring 100% dictionary key parity (1965 keys) across all 4 supported languages.

## Version 23.2.3 — Dark Mode Persistence & Auth Activity Event Fix

- **Dark Mode Appearance Synchronization**: Fixed an issue where clicking anywhere on the desktop or within windows would unexpectedly revert the application to light mode due to user appearance fallback logic.
- **Isolated User Activity Heartbeat**: Separated idle session activity tracking (`recordSessionActivity`) from authentication change events, eliminating continuous dispatch of `socdof-auth-changed` on mouse clicks and keyboard presses.
- **Unified Theme Synchronization**: Synchronized theme switching across company settings, user preferences, and root DOM styling (`document.documentElement.classList`), guaranteeing seamless consistency across light and dark modes.

## Version 23.2.2 — Responsive First-Run Account Onboarding & Authentication Refinements

- **First-Run Language Step**: Language selection is now displayed as the initial onboarding step before prompting to create the first local administrator account.
- **Responsive Layout for Small Displays**: Refactored the onboarding card to fit comfortably on smaller displays and laptop screens with responsive padding, scrolling container limits, and clean vertical rhythm.
- **Default Silhouette & Direct Photo Upload**: Replaced placeholder avatar characters with a standard neutral gray silhouette; users can directly select an image to upload as their profile photo or remove it anytime.
- **Password Strength Meter & Mandatory Indicators**: Added a dynamic password strength bar (Very Weak to Very Strong) with informative hints, plus clear red asterisk markers (`*`) for mandatory fields.
- **Security Questions & Offline Safety Notice**: Provided a dropdown of localized recovery questions plus an option for custom questions, accompanied by an explicit offline recovery notice.
- **Post-Creation Login Redirection**: After successfully creating the first account, the user is redirected directly to the login screen with a success confirmation banner instead of auto-logging in.

## Version 23.0.0 — Windows-Style User & Account Management

### 1. Users & Accounts Settings

- Added a dedicated **Users & Accounts** category to the Settings hub.
- The category is visible and usable only for an active administrator.
- Added Windows-inspired local account management for:
  - account creation
  - display names and usernames
  - administrator/user roles
  - personal/business account types
  - avatars
  - account activation state
  - per-user auto-lock preferences
  - administrator password resets
  - sign-in security thresholds, lockout duration, and exponential backoff

### 2. Start Menu Power Experience

- Moved workstation and account actions into the SOCDOF Start menu.

  - Lock
  - Switch user
  - Sign out
  - Restart workspace
  - Close SOCDOF

- The Start menu user area opens account settings and routes administrators directly to Users & Accounts.

### 3. Localization

- New user-facing strings are sourced from `src/lib/i18n.ts`; no new user-facing strings are hardcoded in the new settings module.

### 4. Documentation
