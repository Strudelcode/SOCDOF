## Version 23.18.1 — Non-Blocking Bounded XML Traversal & Asynchronous File Import Loading
- **Bounded Child Node Traversal for DOCX Parsing**:
  - Replaced recursive DOM element queries (`getElementsByTagName`) in `parseDocxTable`, `parseDocxParagraph`, and `parseDocxXmlContainer` with a non-blocking `getDirectChildrenByTagName` function.
  - Prevents nested table elements from being re-queried as top-level table rows, eliminating exponential CPU loops and freezing on complex Word `.docx` files.
- **Safe PDF Parsing & Timeout Shield**:
  - Configured `pdfjsLib` for synchronous inline parsing without worker CDN cross-origin blocks (`disableWorker: true`, `isEvalSupported: false`).
  - Wrapped PDF extraction in a 10-second safety timeout race promise, ensuring fallback to string stream decoding if a PDF file is locked or corrupt.
- **Asynchronous Loading Indicator & Input Reset**:
  - Added an `isImportingFile` state with a visual loading spinner in the template import dropzone.
  - Reset `fileTemplateInputRef.current.value` after upload completion or failure so users can re-select files seamlessly.
