## Version 23.1.0 — Windows-Style Login & Lock Screen Redesign

### 1. Windows-Style Authentication Surface

- Redesigned the sign-in and workstation lock screens as a full-screen Windows-inspired experience.
- Uses the configured SOCDOF wallpaper as a blurred background with a readable translucent overlay.
- Shows a live clock and date using the configured timezone, date format, language, and seconds preference.
- Added a bottom-left local account switcher with avatar previews and an **Other User** sign-in option.
- Accounts without an uploaded image now render a neutral gray user silhouette instead of a decorative placeholder symbol.

## Version 23.0.0 — Windows-Style User & Account Management

### 1. Users & Accounts Settings

- Added a dedicated **Users & Accounts** category to the Settings hub.
- The category is visible and usable only for an active administrator.
- Added Windows-inspired local account management for:
  - account creation
  - display names and usernames
  - administrator/user roles
  - personal/business account types
  - avatars
  - account activation state
  - per-user auto-lock preferences
  - administrator password resets
  - sign-in security thresholds, lockout duration, and exponential backoff
- Existing last-active-administrator protection remains enforced by the authentication layer.

### 2. Start Menu Power Experience

- Moved workstation and account actions into the SOCDOF Start menu.
- The Start menu power control now exposes:
  - Lock
  - Switch user
  - Sign out
  - Restart workspace
  - Close SOCDOF
- Removed the always-visible authentication management overlay from the desktop workspace.
- The Start menu user area opens account settings and routes administrators directly to Users & Accounts.

### 3. Localization

- Added complete UI translations for the new Users & Accounts settings and Start menu power actions in English, German, French, and Spanish.
- New user-facing strings are sourced from `src/lib/i18n.ts`; no new user-facing strings are hardcoded in the new settings module.

### 4. Documentation

- Extended the in-app documentation with the new Windows-style account-management and Start menu power workflows.
- Documentation remains available in German, English, French, and Spanish.

### 5. Versioning

- Version 23 is an intentional major-version milestone.
- Version metadata is synchronized across `package.json`, `src/lib/version.ts`, `versions/V23.md`, `versions/releases/v23-release.md`, `CHANGELOG.md`, `todo/todo.md`, and `todo/completed_todo.md`.

### 7. Theme & Dark-Mode Hardening
- Added a global compatibility layer for legacy light-only utility classes so dark mode remains consistent across all major desktop surfaces and controls.
- Preserved Light and Dark selection and added a Windows System mode that automatically follows the OS appearance setting.
- Added system-theme translations for EN/DE/FR/ES and documented the behavior in-app.
