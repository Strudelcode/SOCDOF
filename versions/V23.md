## Version 23.11.0 — Invoicing Templates & Layout Architecture in Invoicing & Settings Hub
- **Relocated Template Customization to Core Invoicing & Settings**:
  - Moved template and layout customization out of the Therapy Module into the core Invoicing app (`InvoicesModule`) and Settings Hub under Letterhead (`activeSection === 'letterhead'`).
  - Streamlined the Therapy Module into an uncluttered, focused workspace for client records, sessions, and billing items.
- **Comprehensive Pre-built Invoice Templates**:
  - *DIN 5008 Standard*: German commercial letter standard featuring sender return line, recipient address window, fold and punch marks, itemized line items, and compliant 4-column legal footer.
  - *Modern Minimalist*: Sleek aesthetic with modern typography, subtle header accent line, and clean branding pedestal.
  - *Executive Corporate*: Structured corporate layout with bold accent header bar, logo pedestal top-left, and dedicated banking/registration table.
  - *Creative Studio*: Serif typography, warm tones, and stylish customer appreciation notice.
  - *Praxis / Medical*: Specialized medical invoice template featuring exemption notices according to § 4 Nr. 14 UStG.
  - *Custom Freeform Layout*: Full HTML/CSS editor allowing complete customization with dynamic variables.
- **Interactive Live Preview with 100.000 € Sample Invoice**:
  - Live DIN-A4 document preview with instant toggle between real invoice data and a high-volume 100.000,00 € sample document.
  - Allows quick verification of logo placement, address formatting, number formatting (period thousands and comma cents), and variable replacement.
- **Dynamic Template Variable System & Office File Import**:
  - Centralized in `src/lib/invoiceTemplateManager.ts` with real-time variable scanning for `{Rechnungsnummer}`, `{Datum}`, `{Kunde_Name}`, `{Netto}`, `{Gesamtbetrag}`, etc.
  - Built-in template file importer supporting `.html`, `.docx` text, `.txt`, and `.json` with automatic `{...}` variable detection and mapping.
- **Microsoft Word (.doc) & Print/PDF Export**:
  - Allows 1-click export of any invoice template or active document as a formatted Microsoft Word document (.doc) or DIN-A4 print/PDF.
- **Multilingual Support (DE, EN, FR, ES)**:
  - All template controls, modals, tooltips, and settings descriptions fully localized across English, German, French, and Spanish.

- **Zahlungsarten-Gating (Kassa / Bank)**:
