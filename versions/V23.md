## Version 23.5.0 — Multi-Step System Reset & Complete Reinstallation Flow

- **Multi-Step System Reset Security Workflow**:
  - Implemented an advanced multi-step safety wizard in `SettingsModule.tsx` under "System zurücksetzen" ("Reset System") to prevent accidental data erasure.
  - Step 1: Warning header and detail prompt with strict typed confirmation word ("Löschen" / localized equivalent).
  - Step 2: Explicit confirmation check ("Sind Sie sicher, dass Sie es löschen wollen? / Are you sure you want to delete?") requiring typed word re-entry.
  - Step 3: Local user account password verification via `verifyPassword` to authorize the administrative system reset.
  - Step 4: Final safety checkpoint requiring final word confirmation before triggering the wipe.
  - Step 5: Smooth execution status screen ("Wird zurückgesetzt... / Resetting in progress...") providing immediate visual feedback during database and cache flushing.
- **Multilingual Localization Across All 4 Languages**:
  - Added full translation keys in `src/lib/i18n.ts` for German (`de`), English (`en`), French (`fr`), and Spanish (`es`).
  - Added tolerant localized word verification recognizing "Löschen", "loeschen", "delete", "supprimer", "eliminar", and localized string keys.
- **Complete Storage, Database & Account Purge**:
  - Added `resetEntireSystemDatabase()` in `src/lib/db.ts` to clear all Dexie IndexedDB tables, storage assets, and configuration stores.
  - Added `resetAuthSystem()` in `src/lib/auth.ts` to flush user accounts, credential hashes, and session authentication states.
  - Cleared all browser `localStorage` and `sessionStorage` keys.
  - Redirects smoothly back to the initial first-run onboarding screen for fresh account creation and system configuration.

## Version 23.4.3 — Safe In-App Updates & Persistent Application State

- **Pre-Update Data Protection**:
  - Electron now requests a fresh renderer-side snapshot before an in-app update is downloaded and installed.
  - The snapshot includes the local IndexedDB database and SOCDOF-owned localStorage state, including account-scoped application installation state.
  - The update is aborted if the pre-update snapshot cannot be written successfully.
- **Installer Data Preservation**:
  - Electron Builder is configured with `deleteAppDataOnUninstall: false` so application data is not intentionally removed by the installer.
  - The update continues to replace application files while persistent user data remains outside the application installation.
- **Application Installation Persistence**:
  - Installed App Store modules, including Practice & Therapy, now keep their account-scoped installation state synchronized so reloads and restarts do not silently uninstall them.
- **Documentation**:
  - Added an in-app multilingual explanation of update backups, persistence, and recovery behavior.
