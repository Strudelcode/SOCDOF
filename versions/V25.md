# SOCDOF Version 25 Changelog

All notable changes and technical implementation details for SOCDOF Version 25.x are documented here in English.

## Version 25.2.0 — Custom Roles, Passwordless Accounts & Per-Person Recovery
- **Per-User Language (`src/components/DesktopWindowWorkspace.tsx`)**:
  - Choosing a language in the language dialog now stores it on the signed-in account (`preferences.language`) instead of the shared company profile, so it is not synchronized across users.
- **Custom Roles & App Permissions (`src/lib/auth.ts`, `src/components/UserManagementSettings.tsx`)**:
  - Administrators can create, rename and delete custom roles in the new "Roles & Apps" tab of User Management.
  - Each role has a list of allowed app modules; administrators tick the apps per role.
  - Each non-admin user can be assigned one role (or none, which means full access). Admins always keep full access.
  - Roles are stored in the security settings (`customRoles`); users reference them via `roleId`. Existing accounts are unchanged.
  - Enforced centrally via `canUserAccessModule()` when opening a window (`src/components/DesktopWindowWorkspace.tsx`) and in the command palette (`src/components/CommandPaletteModal.tsx`).
- **Passwordless Accounts for Non-Admins (`src/lib/auth.ts`, `src/components/AuthGate.tsx`)**:
  - Non-admin accounts may be created without a password (`passwordless`). The login card shows a "<Name> continue" button and signs in directly.
  - Administrators always require a password.
- **Per-Person Security Question (`src/lib/auth.ts`, `src/components/AuthGate.tsx`)**:
  - The security question is asked on first sign-in per person (`recoveryPending`) or only once for all users, depending on the setting.
- **Admin View Cleanup (`src/components/UserManagementSettings.tsx`)**:
  - The "Current password" and "Temporary reset" fields are hidden when an administrator edits their own account.
- **Localization (`src/lib/i18n.ts`)**: All new role and passwordless texts are translated in German, English, French and Spanish.

## Version 25.1.0 — Shared Workstation Mode, 1-Click Profile Switching & Portable USB/OneDrive Hardening
- **Single-PC & Shared Workstation Operation Mode (`src/lib/auth.ts`, `src/components/UserManagementSettings.tsx`)**:
  - Implemented dedicated single-PC workstation architecture (`workstationMode: 'single_pc'`) tailored for workshops, small teams, and shared computers where multiple users work together without heavy corporate access barriers.
  - Smooth 1-click user profile switching via `quickSwitchUser()` without forced password prompts or session destruction.
  - Preserves individual desktop personalization, custom wallpapers, pinned taskbars, and language preferences per user while maintaining a shared business database.
- **Start Menu 1-Click User Switcher Flyout (`src/components/DesktopWindowWorkspace.tsx`)**:
  - Added quick profile selection list inside the Start menu Power popover, allowing users to switch immediately between accounts in a single tap.
  - Added direct 1-click login action on the system lock screen and login gate.
- **Fluid Widescreen Settings Layout (`src/components/SettingsModule.tsx`)**:
  - Replaced narrow `max-w-6xl` (1152px) constraint with fluid responsive container `w-full max-w-[1780px] mx-auto`, eliminating wide dark void margins on 1080p, 1440p, and 4K displays.
- **Sticky Tab Headers & Scroll Clipping Protection (`src/components/UserManagementSettings.tsx`, `src/components/SettingsModule.tsx`)**:
  - Made User Management tab headers sticky (`sticky top-0 z-20 backdrop-blur-md`) so navigation stays readily accessible during account scrolling.
  - Added scroll buffer padding (`pt-1 sm:pt-2 px-1`) on `.settings-pane` preventing rounded card corner arcs from getting clipped when scrolling down.
- **Uppercase Initials Avatar System (`src/components/UserManagementSettings.tsx`, `src/components/AuthGate.tsx`)**:
  - Replaced lone unicode bullet points (`●`) with bold, modern uppercase initials badges (`BS`, `AD`, etc.) dynamically styled with system accent colors.
- **Portable Edition & USB / OneDrive Integration (`electron/main.cjs`, `electron/preload.cjs`, `src/components/SettingsModule.tsx`)**:
  - Enhanced portable detection for `--portable` CLI argument, portable executable directories, or adjacent `data/` directories.
  - In portable mode, default automated backups route directly to `<portableDataDir>/backups`, keeping external USB drives completely self-contained.
  - Added dedicated Portable Edition Card in Settings with 1-click Explorer folder opener and OneDrive sync status indicators.
- **Quad-Lingual UI Localization (`src/lib/i18n.ts`)**:
  - Fully translated all new workstation mode options, quick switch toggles, and portable notices in German, English, French, and Spanish.

## Version 25.0.0 — Multi-User Collaboration, Per-User Language Profiles & Advanced Portable Architecture
- **Per-User Language Profiles & OS Synchronization (`src/lib/i18n.ts`, `src/lib/auth.ts`)**:
  - Language settings are now strictly bound to each user account profile (`user.preferences.language`), ensuring multi-user environments do not overwrite each other's language preference.
  - Automatic first-run language detection from OS/browser locale (`navigator.language`) with English fallback.
  - New settings toggle to continuously synchronize language with the computer operating system or lock to manual preference.
- **Abgesicherter Modus & Multi-User Collaboration (`src/lib/auth.ts`, `src/components/AccountScopedWorkspace.tsx`)**:
  - **Business Mode & Sub-Users**: Multi-user workstation support with admin designation on first startup.
  - **Passwordless Quick-Login**: Option for shared collaborative folders where users click to sign in instantly with automatic local change merging.
  - **Real-Time Collision & Presence Warnings**: Active session tracking (`network_session.lock`) detects concurrent usage across network shares or OneDrive folders, prompting: *"Other users are working on this. Continue or cancel?"* with remote auto-save coordination.
- **Portable Setup, Installer & OneDrive Guide (`src/components/DocumentationApp.tsx`)**:
  - Comprehensive explanation of Setup (.exe), Portable (.zip/.exe), and Installer (MSI/NSIS) differences.
  - Full support for OneDrive, Dropbox, and QNAP/NAS network shares in portable data mode.
- **Update Screen & Handbook Polish (`src/components/UpdatingSplashModal.tsx`, `src/components/DocumentationApp.tsx`)**:
  - Polished fluent update progress dialogs with natural status text (no robotic or AI-sounding terminology).
  - Cleaned up SOCDOF Handbook and release history chapters across all 4 languages (`de`, `en`, `fr`, `es`).
- **App Launcher Grid Layout Spacing (`src/components/AppLauncher.tsx`)**:
  - Increased grid row step and bounded card height to prevent multi-line application titles (such as "Praxis & Therapie") from overlapping adjacent rows.
- **Quad-Lingual UI Localization**:
  - All new menus, dialogs, settings, and collaboration warnings fully translated in German, English, French, and Spanish (`src/lib/i18n.ts`).
- **Versioning & Documentation**:
  - Upgraded to Version 25.0.0 across `package.json`, `src/lib/version.ts`, and release logs.
