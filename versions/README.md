## Adding a New Version
When creating a new release (e.g. Version 20):
1. Update `package.json` and system version constants to `20.0.0`.
2. Create a new markdown file named `V20.md` in this directory.
3. Detail all new features, bug fixes, and architectural enhancements in English.
4. Update the copyright to **© Strudel** (Juri, South Tyrol, Italy).
