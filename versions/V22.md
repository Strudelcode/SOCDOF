## 🌟 Version 22.1.3 Release Highlights: Smooth Desktop Widget Dragging Behind Fixed Apps & Dynamic Pointer-Events Isolation

### 1. Fluid Widget Dragging Behind Desktop Apps
- **Seamless Drag Experience**: Dragging widgets (Clock, Calendar, Sticky Notes, KPI tiles) across and behind desktop application icons, folders, and open windows is now completely smooth and responsive without cursor lag, wiggling, or unexpected lock-ups.
- **Pointer-Events Isolation During Drag**: As soon as a user clicks and begins dragging a widget, pointer events on all desktop icons, folders, and windows are temporarily set to `none`. This guarantees that moving the cursor over other applications will not trigger hover highlights, context tooltips, drag-and-drop merges, or capture interrupts.
- **60FPS Drag Engine**: Refactored the widget dragging pipeline to utilize high-performance global window listeners with `requestAnimationFrame` updates. Transitions are bypassed during active dragging to eliminate visual jitter.
- **Natural Occlusion & Gap Picking**: When a widget is positioned behind fixed desktop apps, it stays in the desktop layer underneath. The user can easily grab it whenever an edge or gap is visible, preserving a realistic desktop spatial depth.

## 🌟 Version 22.1.1 Release Highlights: UI Streamlining, Dynamic Directory Resolution & Template Filtering

### 1. UI Clutter Removal & Ergonomic Simplification
- **Removed Redundant Search Inputs**: Eliminated unnecessary "Sprache oder Datei suchen..." search bars in both `LanguageSelectionModal.tsx` and `SettingsModule.tsx`.
- **Eliminated Manual Upload Buttons**: Removed the redundant "Bild zuweisen" / "Flagge zuweisen" buttons in favor of the direct physical `languages/flags/` directory workflow.
- **Cleaned Status Messages**: Removed confusing fallback explanation texts (e.g. "Standard-Fallback: Schwarze Flagge...") for a sleek, enterprise UI.

### 2. Dynamic Language Directory Path Discovery
- **Multi-Location Search**: `electron/main.cjs` dynamically discovers the `languages/` and `flags/` folders by checking:
  1. Environment variable `SOCDOF_LANGUAGES_DIR`
  2. Executable installation directory (`process.resourcesPath`, directory containing `.exe`)
  3. Current working directory (`process.cwd()`)
  4. Standard user data directory (`%APPDATA%/socdof/languages/`)
- **Custom Install Locations**: Works reliably regardless of whether users install or run SOCDOF from non-standard drives or custom folders.

### 3. Automatic Template File Exclusion
- **Template Filter**: Filtered out `template*.json` files from active language dropdowns, detected desktop file lists, and custom pack selections.

## 🌟 Version 22.1.0 Release Highlights: Instant Live-Reload, Selection Module & Flag Customization

### 1. Zero-Restart Live Language Reload
- **Instant Update Pipeline**: Whenever any language JSON file in `languages/` (`%APPDATA%/socdof/languages/` or `public/languages/`) is modified or saved, SOCDOF detects the change via real-time file system watchers (SSE in dev/web and IPC in Electron) and updates all active UI modules in ~200ms without requiring a reload or app restart.
- **Dynamic Language Selection**: Dropdown menu and selection module automatically populate with newly discovered language files, making newly added languages instantly accessible.

### 2. Selection Module & Ergonomic Dropdown
- **Language Selection Module**: Replaced static button grids with a versatile dropdown selector capable of handling dozens of languages, local files, and custom community packs cleanly.
- **Active Preview Card**: Displays the selected language's code, key count, origin, and an active status badge.

### 3. Flag Customization & 3-Tier Fallback Hierarchy
- **Tier 1 - Custom Flag Images**: Users can drop custom flag images into `languages/flags/` (e.g. `de.png`, `fr.svg`, `custom.webp`) or upload directly in the UI.
- **Tier 2 - Clean Standard Emojis**: In the absence of a custom image file, authentic country/regional flag emojis (🇩🇪, 🇺🇸, 🇫🇷, 🇪🇸, etc.) are rendered cleanly.
- **Tier 3 - Default Question Mark Fallback**: For unknown codes or unconfigured files, SOCDOF falls back to a custom-crafted black flag with a centered question mark (`?`).

## 🌟 Version 22.0.0 Major Release Highlights

Version 22 marks a major milestone in SOCDOF's evolution as an internationally extensible, fully localized offline ERP desktop suite:

### 1. Universal English Default Standard
- **English as Universal Master Default**: Formalized English (`en`) as the primary initial default language across the entire application ecosystem:
  - Fresh setups and new installations default immediately to English (`en`).
  - The initial company profile (`defaultCompanyProfile`) initializes in English with standard corporate placeholders.
  - Translation fallbacks strictly resolve against English (`translations.en`) whenever an incomplete third-party language pack is loaded.
  - Full, comprehensive multi-language support remains active and maintained across all 4 built-in languages (`en`, `de`, `fr`, `es`).

### 2. Physical Language Directory, Pre-Generated JSON Files & Real-Time Auto-Reload
- **Physical JSON Files in Repository & Package**:
  - Generated dedicated `.json` translation dictionaries under `/languages/` and `/public/languages/`:
    - `en.json`: Complete dictionary of all 1,039+ English keys, words, phrases, dialog prompts, and buttons.
    - `template_en.json`: Clean boilerplate template for community translations with instructions and metadata.
    - `de.json`, `fr.json`, `es.json`: Full dictionaries for German, French, and Spanish.
    - `README.md` / `README.txt`: Plain-text documentation for non-technical users explaining how to edit with Notepad.
- **Electron Auto-Seeding & Desktop Folder**:
  - On startup or when opening the folder, Electron ensures `%APPDATA%/socdof/languages/` exists and automatically seeds `en.json` and `template_en.json` if absent.
  - Native Windows Explorer button opens `%APPDATA%/socdof/languages/` with 1 click.
- **Real-Time Live Reload (Zero Restart)**:
  - Electron attaches an active file system watcher (`fs.watch`) on `%APPDATA%/socdof/languages/`.
  - When a user opens `en.json` in Notepad, edits any word or phrase, and hits Ctrl+S, Electron detects the write and dispatches `socdof:languages-folder-changed`.
  - The i18n engine dynamically re-reads the JSON, merges the updated strings into memory, and triggers instantaneous React UI re-renders without needing to restart the app.
  - Dropping any new language file (e.g. `italian.json`) into the directory immediately lists it in Settings as a selectable language.

### 3. Modular JSON Translation Template & Exporter
- **1-Click Template Download**: In Settings under "Language & Region", users can download `socdof-language-template.json` prefilled with all English master keys, complete with metadata headers and instructions.
- **Live System Language Exporter**: Allows exporting any currently loaded built-in language (`socdof-language-en.json`, `socdof-language-de.json`, `socdof-language-fr.json`, `socdof-language-es.json`) to serve as a translation base or for custom dialect creation.
- **Dynamic File Importer**: Instant file parser supporting both structured metadata JSON (`{ _metadata, translations }`) and flat translation dictionaries (`{ key: value }`).
- **Live Pack Management**: Custom imported packs can be activated, switched, or removed in real-time with instant system-wide UI updates and zero page reloads.

### 4. Re-architected Settings Hub & Master Volume Control
- **Categorized Hub Architecture**: Grouped settings into 4 ergonomic categories:
  1. **Overview & Quick Controls**: Status dashboard, Dark Mode switch, Master Volume slider, and quick links.
  2. **Business & Finance**: Company data, invoice numbering, DIN 5008 letterhead, Google Calendar live 2-way sync, and automatic backups.
  3. **Appearance & Personalization**: Visual theme, accent colors, custom language packs, and procedural audio settings.
  4. **System & Devices**: Windows desktop launcher, developer diagnostics, and offline storage management.
- **Continuous Master Volume Slider**: 0% to 100% precision audio slider with preset buttons (`15%`, `35%`, `60%`, `85%`, `100%`) and test audition trigger.
- **Rich Procedural Audio Library**: Integrated real-time Web Audio API effects for payments, cash register drawers, coin clinks, NFC contactless beeps, service bells, and milestone fanfares.
