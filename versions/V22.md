## 🌟 Version 22.9.0 Release Highlights: Robust Contact Import & Export Engine, Guestbook / Address Book Filter & Outlook/CSV/vCard Support

### 1. Intelligent Contact Import Engine (`src/lib/contactImportExport.ts`)
- **Full RFC 4180 CSV Compliant Parser**: Accurately parses CSV files with quoted multiline values, escaped quotes, and varying newline conventions (`\r\n`, `\n`).
- **Delimiter Auto-Detection**: Dynamically sniffs whether the imported file uses semicolons (`;`), commas (`,`), or tabs (`\t`) based on header occurrence.
- **Smart Column Detection**: Comprehensively maps international, German, and English headers (e.g. `Vorname`, `Nachname`, `First Name`, `Last Name`, `E-Mail-Adresse`, `Company`, `Firma`, `Mobiltelefon`, `Strasse`, `PLZ`, `Ort`, `Notizen`).
- **Compound Name Assembly**: Seamlessly combines separate `First Name` + `Middle Name` + `Last Name` columns into unified contact names.
- **vCard (.vcf) Import Engine**: Supports vCard 2.1, 3.0, and 4.0 files exported from Outlook, Apple Contacts, or Google Contacts.

### 2. Zero Artificial / Placeholder Emails
- **Strict User Intent Respect**: If an imported contact contains an email, it is preserved. If only a name or company is provided, the contact is saved cleanly without generating fake placeholder emails like `kontakt_X@import.local`.
- **Database Sanitizer**: Automatic cleanup (`sanitizeLegacyContacts`) executes on mount to purge dummy emails from past faulty imports while preserving all real names, companies, and phone numbers.

### 3. Dedicated "Gästebuch / Adressbuch" (Guestbook / Private) Mode
- **Contact Type Extension**: Introduced the `guest` contact type for private contacts, personal guestbook entries, friends, or non-commercial address book records.
- **Distinct Visual Badge**: Highlighted with an elegant teal badge in contact lists and detail cards.
- **Filter Tab**: Added a dedicated "Gästebuch / Adressbuch" filter tab in the Contacts toolbar with live counter badge.
- **Quad-Language Parity**: Localized as "Guestbook / Private" (EN), "Gästebuch / Privat" (DE), "Livre d'or / Privé" (FR), and "Libro de visitas / Privado" (ES).

### 4. Comprehensive Contact Export (CSV & vCard)
- **1-Click Export Dropdown**: Fast export to CSV (Excel-compatible with UTF-8 BOM) or vCard format (.vcf).
- **Export Scope Selection**: Technicians can export all contacts in the database or only the currently active filtered view.

### 5. Interactive Import Preview Modal
- **Target Category Switcher**: Choose whether to import contacts into the Guestbook (`guest`), Customers (`customer`), or Suppliers (`vendor`).
- **Granular Row Removal**: Easily delete unwanted preview entries before committing to the database.
