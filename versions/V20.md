# SOCDOF – Version 20 Release Notes

## Version v20.0.0 (2026-08-25)

### 1. App Store Vertical Scrolling & Layout Resilience
- **Full-Height Scroll Container**:
  - Restructured the root container of `AppStoreModule.tsx` with `h-full overflow-y-auto` and adaptive padding (`p-4 sm:p-6`).
  - Allows smooth vertical scrolling across all application categories, promotional banners, installable apps, and pinned module cards.

### 2. Desktop Workspace Interaction & Pointer Cursors
- **Native Pointer & Default Cursor Pairing**:
  - Removed persistent grabbing cursors (`cursor-grab`) from desktop icon outer bounds in favor of clean desktop navigation.
  - Interactive icons utilize `cursor-pointer` on click with immediate feedback.
- **Grayscale & Opacity Feedback During Drag**:
  - Dragged desktop icons and folders display subtle grayscale filtering and reduced opacity (`opacity-30 scale-95 filter grayscale`), providing crisp visual dragging cues.

### 3. Taskbar Drag-and-Drop Visual Insertion Indicator
- **Vertical Guide Line ("Strick") on Taskbar**:
  - Integrated dynamic `dragOverTaskbarIdx` tracking on pinned taskbar applications.
  - Displays a pulsed vertical indicator line (`w-1 bg-indigo-500 rounded-full shadow-lg animate-pulse`) at the exact target slot during drag-and-drop reordering.

### 4. Dynamic Timezone Synchronization & System Clock
- **Live Regional Timezone Formatting**:
  - Integrated `formatSystemTime` and `formatSystemDate` with company profile timezone (`company.timezone`).
  - Taskbar digital clock, system date string, and Windows 11 calendar flyout automatically update to reflect the configured timezone (e.g. `Europe/Berlin`, `Europe/London`, `America/New_York`, `UTC`).

### 5. Settings Storage Metric Explanation & Renaming
- **IndexedDB Footprint Explanation**:
  - Added descriptive guidance and tooltip clarifying that the storage metric measures total local IndexedDB database usage across invoices, contacts, products, journal entries, POS receipts, and logos.
- **Unified Section Naming**:
  - Renamed sidebar section to **"Sprache, Region & Zeit"** / **"Language, Region & Time"** to reflect timezone, date format, seconds display, and localization settings.

### 6. Structured Contacts Form Refactoring
- **Granular Address & Profile Inputs**:
  - Refactored customer edit modal with separate, dedicated inputs for ZIP Code (`PLZ`), City/Town (`Stadt`), Country (`Land`), Tax Identification Number (`USt-IdNr.`), and internal notes (`Notizen`).

### 7. Documentation Architecture & Version 20 Alignment
- **Synchronized Versioning**: Updated `package.json`, `src/lib/version.ts`, `metadata.json`, and `versions/` index to Version 20.
- **Dedicated Release Summary**: Created `versions/releases/v19-release.md` summarizing the entire Version 19 lifecycle.
- **English Documentation**: Standardized all version files and developer notes to English.
