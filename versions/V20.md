# SOCDOF – Version 20 Release Notes

## Version v20.0.9 (2026-08-26)

### 1. Dynamic Semantic Release Tagging
- **Semantic Version Tags**:
  - Replaced single-tag overwriting with unique semantic tags (e.g. `v20.0.9`, `v21.0.0`, `v33.0.0`) dynamically extracted from `package.json`.
  - Conforms to standard Git and GitHub Release immutability principles, preventing cache issues and download checksum discrepancies.

### 2. Multi-Major Scalability
- **Universal CI/CD Pipeline**:
  - GitHub Actions workflow in `.github/workflows/build-windows-exe.yml` dynamically operates with any major version (`v20`, `v21`, `v33`, etc.) without hardcoded values.
  - Release documentation notes are automatically resolved from the corresponding `versions/V<major>.md` file.

### 3. Native GitHub Release Publishing & Latest Pointer
- **Automated Latest Flag**:
  - Sets `make_latest: true` to ensure the newest build is always designated as GitHub's official latest release for automated in-app update checks.

## Version v20.0.6 (2026-08-26)

### 1. Automated GitHub Actions CI/CD Pipeline
- **Push & Tag Automation**:
  - Automatically triggers on every push to `main`/`master` as well as any version tags (`v*`).
  - Automatically checks if the major version root tag (e.g. `v20`, `v19`) exists on GitHub. If not found, it creates and pushes the major tag.
  - Automatically builds the standalone Windows Setup installer `.exe` with Electron Builder.

### 2. Intelligent Release vs. Pre-release Segregation
- **Milestone Versioning Logic**:
  - Major root releases (`20.0.0`, `19.0.0`) are published directly as standard GitHub **Releases** (`prerelease: false`).
  - Intermediate sub-versions and patches (`20.0.6`, `20.0.5`, `20.1.0`) are published as GitHub **Pre-releases** (`prerelease: true`).

### 3. Automated Release Notes Extraction
- **Documentation Sync**:
  - `scripts/prepare-release.cjs` dynamically parses `versions/V*.md` for the matching version section and injects the formatted changelog into the GitHub release description.

### 4. Strict In-App Update Filter
- **Stable-Only Updates**:
  - Updated `src/lib/updateChecker.ts` so the in-app automatic update detector strictly verifies official full releases and completely filters out all pre-releases from prompting normal users.

## Version v20.0.5 (2026-08-26)

### 1. Automated Database Backups & Periodic Snapshot Engine
- **Automated Background Backup Cycle**:
  - Implemented background interval loop in `App.tsx` executing `checkAndRunAutoBackup` at configured intervals (from 10 minutes to 24 hours).
  - Snapshot engine generates local JSON backups with metadata (timestamp, record count, byte size) stored in IndexedDB/LocalStorage.
  - Added full backup manager UI in Settings with on/off toggle, configurable interval, custom folder path, manual snapshot button, and 1-click snapshot restore.
  - Enabled direct download of backup snapshots as `.json` files.

### 2. Native Desktop Taskbar "Web-Vorschau" Badge Isolation
- **Environment Detection & Clean Native UI**:
  - Wrapped the "Web-Vorschau" notification badge in `DesktopWindowWorkspace.tsx` with `!isDesktopApp` (using `isElectron()` runtime check).
  - Ensures the badge is visible strictly when testing in web browsers/preview mode and completely hidden in the native packaged Windows Electron desktop app.

### 3. Italian FatturaPA XML Importer & SdI Parser
- **Electronic Invoice Ingestion**:
  - Implemented `src/lib/fatturaPaParser.ts` for parsing Agenzia delle Entrate / SdI FatturaPA 1.2.x XML documents (`TD01`, `TD04`, `TD06`...).
  - Added XML upload/drag-and-drop importer button in `InvoicesModule.tsx`.
  - Interactive preview modal displaying invoice number, date, currency, total gross amount, seller (Cedente/Prestatore) & buyer (Cessionario/Committente) data, line items with tax breakdown, and payment IBAN.
  - 1-click import into SOCDOF customer invoice journal with automatic partner creation or linking.
