# SOCDOF – Version 20 Release Notes

## Version v20.4.0 (2026-08-26)

### 1. Developer Code Signing & SmartScreen Resolution
- **Authenticode Developer Signature Scripts**:
  - Implemented `scripts/create-dev-cert.ps1` to generate a 5-year self-signed developer certificate for `CN=Yuri / Strudel, O=Strudelcode, C=DE` and install it into the Windows Trusted Root Certification Authorities store.
  - Implemented `scripts/sign-windows-exe.ps1` to apply dual SHA256 Authenticode signatures and DigiCert RFC-3161 timestamps to all Windows installer binaries (`SOCDOF-Setup-*.exe`).
  - Configured `electron-builder.json` with developer publisher identity (`publisherName: "Yuri / Strudel"` and `artifactName: "SOCDOF-Setup-${version}.${ext}"`).
- **Interactive Code-Signing Guidance**:
  - Added dedicated "Code-Signing & SmartScreen" tab in `WindowsDesktopManagerModal` with clear step-by-step instructions and one-click copyable PowerShell commands to eliminate Windows SmartScreen warnings on client workstations.

### 2. Two-Way Calendar Integration (iCal, Google Calendar & Microsoft Outlook)
- **RFC 5545 iCalendar (`.ics`) Parser & Generator**:
  - Created `src/lib/ical.ts` supporting RFC 5545 compliant `.ics` file generation for all invoice due dates, customer milestones, and company profile info.
  - Added client-side `.ics` import parser with UID-based deduplication and IndexedDB/localStorage persistence.
- **Google Calendar & Outlook 1-Click Integration**:
  - Added direct webcal subscription link generation (`webcal://...`) with instant clipboard copy.
  - Added one-click action buttons to launch Google Calendar (`render?action=TEMPLATE&...`) and Microsoft Outlook directly in the browser with prefilled calendar subscriptions.
- **Windows 11 Agenda Flyout Integration**:
  - Enhanced the Windows 11 taskbar clock calendar flyout to aggregate both invoice due dates and imported external calendar events with custom event tags and click navigation.
- **Multilingual Support**:
  - Full translations for all connection, calendar, and code-signing features in German, English, French, and Spanish (`src/lib/i18n.ts`).

## Version v20.3.0 (2026-08-26)

### 1. Italian E-Invoicing (FatturaPA 1.2.2 & SdI Full Lifecycle)
- **FatturaPA 1.2.2 XML Generator**:
  - Implemented compliant FatturaPA 1.2.2 XML generator supporting both `FPR12` (private B2B/B2C transactions) and `FPA12` (Pubblica Amministrazione).
  - Fully incorporates required Italian tax metadata: Codice Destinatario (7 characters or 6 for PA), PEC delivery addresses, tender codes (CIG & CUP), virtual stamp duty (Bollo Virtuale 2,00 €), tax regimes (RF01-RF19), and Natura exemption codes (N1-N7).
- **SdI Receipt & Notification Parser**:
  - Engineered parser for official Agenzia delle Entrate / Sistema di Interscambio notification receipts: `RC` (Ricevuta di Consegna), `NS` (Notifica di Scarto), `MC` (Mancata Consegna), `NE` (Notifica Esito Committente PA), `DT` (Decorrenza Termini), and `AT` (Attestazione Trasmissione).
  - Integrated SdI Error Code Catalog with descriptions and actionable troubleshooting hints across all 4 languages (DE, EN, FR, ES).
  - Intelligent file auto-detection distinguishing between FatturaPA invoice XMLs and SdI receipt notifications on upload.
- **Interactive FatturaPA & SdI Inspector Modal**:
  - Dedicated inspection modal with live syntax-colored XML inspection, one-click clipboard copying, XML download, and SdI lifecycle tracking (Not Sent, Sent, Delivered, Rejected, Failed Delivery, PA Accepted, PA Refused).
  - Ability to manually upload or assign SdI receipt files directly to invoice records, automatically synchronizing delivery timestamps and error details.
- **Enhanced Contacts & Settings Integration**:
  - Added dedicated Italian SdI fields in Company Settings and Contact editor (Codice Destinatario, PEC, Tax ID / Codice Fiscale, Regime Fiscale, Bollo default), which auto-populate into new invoices.

### 2. Global Search & Command Palette Polish
- **Harmonized Branding**:
  - Replaced legacy labels with SOCDOF suite branding throughout the Command Palette (`Ctrl+K`).
- **Comprehensive Entity Search**:
  - Real-time search across CRM Contacts, Product SKUs, Invoices, and quick action shortcuts.
