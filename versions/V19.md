# SOCDOF – Version 19 Release Notes

## Version v19.0.3 (2026-08-25)

### 1. Windows 11 Style Calendar & Agenda Flyout
- Clicking the taskbar digital clock opens an authentic Windows 11 flyout menu in the bottom-right corner.
- Full digital time with live seconds, localized weekday and date header, and quick "Heute" navigation button.
- Month view grid with weekday headers (`Mo`–`So`), month navigation buttons (`<` / `>`), active day highlighting, and deadline event dots.
- Agenda section ("Termine & Fälligkeiten") showcasing due dates and open invoices with one-click direct navigation into the invoices module.
- Smooth close-on-outside-click handling for seamless desktop usability.

### 2. Exit Confirmation & Standby Polish
- Clicking "Beenden" in the Start Menu presents an explicit confirmation dialog: *"SOCDOF beenden? Möchten Sie die Desktop-Umgebung wirklich schließen?"*
- Explicit action choices: *"SOCDOF jetzt beenden"* (locks session/closes windows), *"Arbeitsbereich neu starten"* (fresh boot), and *"Abbrechen"*.
- Updated standby/lockscreen and restart notifications to consistent SOCDOF branding.

## Version v19.0.2 (2026-08-25)

### 1. Duplicate Tooltip Bugfix & Desktop Hover Polish
- Removed standard HTML `title` attributes from desktop application icons and desktop folders.
- Prevents the browser and Electron from rendering a redundant, unstyled native OS/browser tooltip on top of the custom SOCDOF design tooltip.
- Ensures a single, consistent, polished tooltip presentation across both the Web preview and native Windows `.exe` desktop builds.

## Version v19.0.1 (2026-08-25)

### 1. Dedicated `.exe` branding & icon configuration
- Configured native SOCDOF SVG/Icon targets in `electron/main.cjs` and `electron-builder.json`.
- Removed default Electron window references for clean standalone Windows packaging.

### 2. Clean desktop workspace launch
- App opens directly onto the clean SOCDOF desktop with icons and folders; does not force open the dashboard or overview window automatically.

### 3. Desktop icon name tooltips
- Added a responsive ~0.6s hover delay tooltip for desktop app icons and folders displaying full names and metadata.

### 4. Start menu search field fix
- Interacting with the Start Menu search input now retains focus without triggering unintended menu dismissal.

### 5. Streamlined Start Menu quick actions
- Removed redundant `.EXE Download` and `Windows App` buttons from the Start Menu quick bar in favor of a clean, responsive 4-action bar (Language, Docs, GitHub, Discord).

### 6. SOCDOF-native terminology in stock & launcher
- Replaced legacy `Odoo-Prinzip` with `SOCDOF-Prinzip: Doppelte Lagerbuchführung` in `StockMovesModule.tsx` and updated launcher footer branding.

## Version v19.0.0 (2026-08-24)

### 1. Language synchronization and multilingual interface

- Synchronized all visible Settings texts through the `t()` translation helper.
- Covered General, Personalization, theme mode, Mica effect, system language, region, and currency settings.
- Added consistent English, German, French, and Spanish UI translations.
- Removed unintended German fragments when another language is selected.

### 2. Button visuals and accent-color contrast

- Improved hover contrast for accent-color buttons such as Purple, Cyber Blue, and Windows Indigo.
- Labels remain readable in both light and dark modes.
- Active windows, focused cards, and selected navigation tabs now use the configured system accent color through `var(--accent)`.

### 3. Configurable and synchronized date format

- The taskbar date format is read from the company profile (`company.date_format`).
- The default `DD.MM.YYYY` format preserves leading zeroes, for example `24.08.2026` and `02.04.2026`.
- Supported formats include `DD.MM.YYYY`, `YYYY-MM-DD` (ISO), and `MM/DD/YYYY` (US).
- Changes made in Settings update the taskbar clock immediately.

### 4. Suppressed `.exe` download reminder in the native desktop app

- In native Windows/Electron environments (`navigator.userAgent`, `process.versions.electron`, `isElectron`, or the `file:` protocol), the download toast is suppressed.
- In the browser preview, the notification appears discreetly after 60 seconds and can be dismissed permanently or for the current session.

### 5. Save confirmation

- Added a floating status toast confirming that changed settings were saved locally.
- Added a manual quick-save button to the left sidebar.
