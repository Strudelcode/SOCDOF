# SOCDOF – Version 19 / 20 / 21 Release Notes

## Version v21.8.4 (2026-09-02)

### 1. Task View System Feature Alignment (Removed Dot Indicator)
- **Authentic Windows 11 Shell Behavior**:
  - Removed the active indicator dot from the Task View taskbar icon button.
  - Task View is an intrinsic background desktop management utility, and therefore does not show an active open app dot indicator on the taskbar.

### 2. Semi-Transparent Desktop Placement Ghost (Drag & Drop Preview)
- **Real-Time Snap Ghosting**:
  - When dragging an application or folder across the desktop canvas, a semi-transparent, pulsed ghost element renders in real-time at the target grid position (`x, y`).
  - Displays the module's colored icon, title, and dashed boundary so users clearly understand where the icon will land prior to releasing the mouse button.

### 3. Complete Widgets 4-Language Localization
- **100% Multilingual Parity in DE, EN, FR, ES**:
  - Fully translated all widget catalog entries, descriptions, button labels, time formatting options, background styling options, and typography selectors in `src/lib/i18n.ts`.
  - Localized `WidgetsModule.tsx`, `WidgetSettingsModal.tsx`, and `DesktopWidgetsModal.tsx`.

## Version v21.6.3 (2026-09-01)

### 1. Start Menu Context Menu Isolation & State Preservation Fix
- **Selective Context Menu Dismissal**:
  - Removed full-screen overlay interception that was inadvertently capturing inside clicks as outside clicks.
  - Clicking anywhere inside the Start Menu (search field, category buttons, blank areas, profile section) now closes only the active context menu while keeping the Start Menu reliably open.
- **External Click Dismissal**:
  - Clicking outside the Start Menu (on the desktop canvas, open windows, or the taskbar) continues to close both the context menu and the Start Menu naturally.

## Version v19.0.0 (2026-08-24)

### 1. Language synchronization and multilingual interface

- Synchronized all visible Settings texts through the `t()` translation helper.
- Covered General, Personalization, theme mode, Mica effect, system language, region, and currency settings.
- Added consistent English, German, French, and Spanish UI translations.
- Removed unintended German fragments when another language is selected.

### 2. Button visuals and accent-color contrast

- Improved hover contrast for accent-color buttons such as Purple, Cyber Blue, and Windows Indigo.
- Labels remain readable in both light and dark modes.
- Active windows, focused cards, and selected navigation tabs now use the configured system accent color through `var(--accent)`.

### 3. Configurable and synchronized date format

- The taskbar date format is read from the company profile (`company.date_format`).
- The default `DD.MM.YYYY` format preserves leading zeroes, for example `24.08.2026` and `02.04.2026`.
- Supported formats include `DD.MM.YYYY`, `YYYY-MM-DD` (ISO), and `MM/DD/YYYY` (US).
- Changes made in Settings update the taskbar clock immediately.

### 4. Suppressed `.exe` download reminder in the native desktop app

- In native Windows/Electron environments (`navigator.userAgent`, `process.versions.electron`, `isElectron`, or the `file:` protocol), the download toast is suppressed.
- In the browser preview, the notification appears discreetly after 60 seconds and can be dismissed permanently or for the current session.

### 5. Save confirmation

- Added a floating status toast confirming that changed settings were saved locally.
- Added a manual quick-save button to the left sidebar.
