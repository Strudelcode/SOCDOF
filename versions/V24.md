All notable changes and technical implementation details for SOCDOF Version 24.x are documented here in English.

## Version 24.8.2 — Company Contacts with Sub-contacts, Split Name Fields & Country Live Autocomplete
- **Company-First Contact Workflow**:
  - Contacts can now be registered solely by company name (`Firmenname (Fa.) *`), without requiring artificial personal name fields.
  - Form validation, normalization, and display adapt cleanly whether creating a business or a private individual.
- **Dedicated Sub-contacts (Kontaktpersonen) for Companies**:
  - Added support for adding, editing, and managing multiple contact partners (sub-contacts) directly under a company:
    - Dedicated separated fields for First Name (`Vorname`) and Last Name (`Nachname`).
    - Contact details: Email address and phone number with direct dial/mailto integration.
    - Role & position designation (e.g., Managing Director, Purchasing, Accounting, Sales).
    - Star badge for setting and designating the primary business contact (`Hauptkontakt`).
- **Divided First and Last Name Fields for Individuals**:
  - Individual person contacts (`Privatperson / Einzelperson`) now feature explicitly separated fields for First Name (`Vorname *`) and Last Name (`Nachname *`), ensuring clean address book organization and accurate vCard/export generation.
- **Interactive Live Country Autocomplete with Keyboard Navigation**:
  - Typing the initial letters into the Country (`Land`) field reveals a real-time suggestions dropdown featuring country flag emojis, localized country names in all 4 languages, and ISO-3166-1 alpha-2 codes.
  - Implemented full keyboard navigation (`ArrowDown` / `ArrowUp` to navigate, `Enter` to select without prematurely submitting the modal, `Escape` to close).
- **Sub-contact Visibility in Details & Search**:
  - `ContactDetailModal.tsx` now prominently renders the company's sub-contacts section with one-click copy buttons for email and phone numbers.
  - `ContactsModule.tsx` and `CustomerPickerModal.tsx` search filters now index all sub-contacts so searching for an employee's first name, last name, email, or role immediately displays the associated company.
  - Contact cards render a clean sub-contact indicator badge with the primary contact partner.
- **Universal 4-Language Localization**:
  - Added full translation support across English, German, French, and Spanish in `src/lib/i18n.ts` for all sub-contact management, roles, and country autocomplete dialogs.

## Version 24.6.7 — Fix False "Post existiert nicht mehr" in Discord Ticket Overview
- **Prevent False Deleted Flags for Webhook & BotGhost Tickets**:
  - Reports created via BotGhost or webhook mechanisms utilize non-snowflake identifiers (e.g. `bg_...`). Previously, the sync engine attempted to query Discord's channel endpoint with these IDs, which returned 404 and erroneously marked reports as deleted.
  - Restricted Discord REST channel sync exclusively to valid 17-20 digit snowflake thread IDs (`/^\d{17,20}$/`).
- **Permission & Status Code Isolation**:
  - Removed HTTP 403 (Forbidden / Missing Permissions) and HTTP 401 from triggering `isDeleted: true`. Only authenticated and verified HTTP 404/410 responses mark a thread as deleted.
- **Auto-Healing for Existing Local Reports**:
  - Implemented automatic self-healing in `getSubmittedDiscordReports()` and `syncDiscordReports()` to restore active tickets previously affected by the false deleted flag.
