# SOCDOF Version 24 Changelog

All notable changes and technical implementation details for SOCDOF Version 24.x are documented here in English.

---

## Version 24.4.0 — Word (.docx) Multi-Page Table Engine, Templates Folder Watcher & PDF Stationery Placement
- **Deep Binary Word (.docx) Table AST Engine (Roadmap 2.4)**:
  - Full two-pass cell matrix resolution for complex Word tables across multiple pages.
  - Implemented vertical cell merging resolution (`w:vMerge` with `restart` and continuation calculating rowSpan, activeMerges map, and skip markers).
  - Implemented horizontal grid spanning (`w:gridSpan` to colSpan calculation).
  - Added support for row properties `w:trPr` including `w:cantSplit` preventing table rows from splitting across page breaks (`page-break-inside: avoid; break-inside: avoid;`) and row background shading (`w:shd`).
  - Seamless support for nested XML tables inside cells (`parseDocxXmlContainerAsync`).
- **Desktop Templates Folder Watcher & Live Auto-Sync (Roadmap 2.4)**:
  - Real-time synchronization of the external templates folder `%APPDATA%/socdof/templates` (or portable `templates/` directory).
  - Integrated Electron IPC file watcher with `onTemplatesFolderChanged` callback for instant UI updates when templates are added or edited.
  - Enhanced Template Manager with live sync status badge ("Auto-Sync aktiv"), folder opener for Windows Explorer (`openTemplatesFolder`), and quick refresh.
  - Detected template cards with format badges (`.docx`, `.pdf`, `.html`, `.json`), file size, last modified date, and 1-click import.
- **Direct PDF Form-Field Token Injection & Interactive Visual Placement Tool (Roadmap 2.4)**:
  - Interactive DIN-A4 visual placement canvas (`stationeryCanvasRef`) allowing users to position tokens directly onto PDF or image letterheads.
  - Interactive mouse and touch drag-and-drop token placement with real-time percentage coordinates (`xPct`, `yPct`).
  - Click-to-place capability: clicking any position on the canvas instantly moves the currently selected field there.
  - Dedicated Token Inspector panel with:
    - Variable selector dropdown (`AVAILABLE_INVOICE_VARIABLES`).
    - Position X/Y sliders (0% – 95%) with numeric feedback.
    - Width slider (10% – 90%).
    - Font-size slider (8px – 28px).
    - Font-weight selector (Normal vs. Bold).
    - Text alignment selector (Left, Center, Right).
    - Field deletion.
  - Quick action to place default invoice layout tokens (`{Rechnungsnummer}`, `{Datum}`, `{Kunde_Name}`, `{Kunde_Adresse}`, `{Kunde_PLZ_Ort}`, `{Positionen_Tabelle}`, `{Gesamtbetrag}`).
- **High-Resolution PDF-to-Image Letterhead Rendering**:
  - Implemented `renderPdfFirstPageToImageAsync` using `pdfjs-dist` to convert uploaded PDF letterheads into crisp, 2x print-resolution PNG graphics directly in the browser/Electron runtime.
- **Quad-Language Localization**:
  - All new stationery and folder watcher UI strings translated across German, English, French, and Spanish.

## Version 24.3.0 — Default Edge-to-Edge Borderless Fullscreen & Top-Edge Quick Window Controls
- **Default Fullscreen Launch Mode**:
  - SOCDOF automatically starts in full edge-to-edge borderless mode covering the entire screen and Windows taskbar by default.
  - Full parity across native Electron runtime (`fullscreen: true`, `mainWindow.setFullScreen(true)`) and Web browsers via automated fullscreen requests.
- **Top-Right Windows Window Controls**:
  - Added a non-intrusive frosted-glass window control pill to the top right of the screen.
  - Provides instant access to standard window controls:
    - **Minimieren (Minimize `-`)**: Minimizes the app to the Windows taskbar in Electron or shrinks the window.
    - **Vollbild / Fenster-Modus (F11 `🗖` / `🗗`)**: Toggles seamlessly between borderless edge-to-edge fullscreen and windowed / resized desktop mode ("kleiner machen / größer machen").
    - **Schließen (Close `✕`)**: Standard Windows exit / shutdown action.
    - No logout button in the top bar, preserving clean window management without accidental session termination.
- **Full Light-Mode & Dark-Mode Parity**:
  - Top-right window controls bar, fullscreen launch switch, and all modules (Purchases, Contacts, Products, Support) feature complete light-mode and dark-mode styling with zero hardcoded dark-only colors and high-contrast text.
- **Complete Suite Dynamic Accent & Anti-Clash Contrast Harmonization (Roadmap 2.1)**:
  - All remaining modules (Contacts & CRM, Inventory & Products, Purchases & Procurement, Support & Services, Praxis & Therapy, Bug Reports & Feedback, Settings & Personalization) now dynamically derive colors from `--accent`, `--accent-light`, and `--accent-companion`.
- **Universal F11 & Window Minimize Support**:
  - Global F11 key shortcut support across Login screen, Lock screen, Desktop workspace, and open modals.
  - Native IPC handlers in Electron (`socdof:minimize-window`, `socdof:set-fullscreen`, `socdof:maximize-window`, `socdof:unmaximize-window`, `socdof:is-maximized`).
- **Settings Toggle for Fullscreen Startup**:
  - Added persistent toggle in Settings > Windows (`socdof_start_fullscreen`) enabling users to customize their default launch preference.
- **Quad-Language Localization**:
  - New window controls, tooltips, and settings descriptions translated across German, English, French, and Spanish in `src/lib/i18n.ts`.

## Version 24.2.0 — Mobile Therapy Dossier Timer, Window Auto-Fit Hardening & Responsive Verification (Phase 12)
- **Mobile Consultation Timer (Phase 12)**:
  - Client dossier (`TherapyClients.tsx`) gains a start/stop consultation timer visible only in compact layouts (< 640px container width).
  - Timer state persists via `localStorage` (`socdof_therapy_consultation_timer_v1`) so running sessions survive window switches and app restarts (crash recovery).
  - Live display updates every second; stopping opens the quick session note sheet with the elapsed time pre-computed.
- **Quick Session Note Bottom Sheet (Phase 12)**:
  - Mobile-only bottom sheet capturing intervention and progress note; session duration auto-derived from the running timer (defaults to 50 min when no timer ran).
  - Saves directly into the practice session history via `onQuickSessionSave` handler in `TherapyPracticeModule.tsx` with toast feedback.
- **Live Viewport Auto-Fit (Window Manager)**:
  - `DesktopWindowWorkspace.tsx` now listens to viewport resize: below 768px width all open windows maximize to full viewport (matching `openWindow` mobile behavior); at larger sizes geometry is clamped into visible bounds.
  - Fixes clipped/off-screen windows when resizing an already-open window on narrow screens (previously sizing only applied at window open time).
- **Calendar Duplicate Day View Fix**:
  - Desktop day list is now hidden when the mobile hour-marker agenda is active (`viewMode === 'day' && !isMobileLayout`), eliminating double-rendered day surfaces on narrow windows.
- **Localization**: New therapy timer & note surfaces fully translated in `src/lib/i18n.ts` across German, English, French, and Spanish (`therapy.timer*`, `therapy.quick_note*` keys).
- **ERP Dashboard Dynamic Accent & Anti-Clash Harmonization (Roadmap 2.1)**:
  - All dashboard KPI icon chips, period filter chips, list accents, empty-state CTAs and footer action buttons are now driven by the `--accent` / `--accent-light` CSS variables and re-tint live with the Color Picasso accent picker.
  - Anti-clash dual-series design: secondary metric series (POS revenue, inventory value, stock move income) intentionally use the contrasting `--accent-companion` variable so primary (revenue) and secondary (expenses/stock) series never visually collide — verified with a runtime accent override.
  - New POS revenue KPI card surfacing the previously unused `totalPosRevenue` aggregation together with the POS order count, navigating to the cash register on click.
  - New Quick Launchpad section with four one-tap daily workflow actions (new invoice, POS sale, new contact, stock booking) alternating accent & companion icon chips.
  - Onboarding zero-state step cards switched from fixed purple/teal to dynamic accent variables; legacy seeded placeholder company names ("Your Company Name" / "Ihr Firmenname" / "SOCDOF") no longer leak into the welcome headline (same trio filter as AuthGate onboarding).
  - Full localization: 70 new `dashboard.*` i18n keys across German, English, French, and Spanish; no hardcoded UI strings remain in the module.
- **Phases 14 & 15 Verification + Web-Preview Parity Notice**:
  - Settings & Personalization (Phase 14) and App Store & Documentation (Phase 15) visually verified at 380px viewport width: no clipped surfaces, touch-friendly cards and scrollable filter chips.
  - New parity banner in Settings > Windows when running in the browser (`!isElectron()`): explains Electron-only differences and the full web fallbacks for update install and backup folder picking (`settings.web_preview_parity_title/desc` i18n keys) for true 1:1 web testing.

## Version 24.1.0 — Mobile Calendar Day Agenda & Support Time-Tracking Layouts (Responsive Phases 10 & 11)
- **Mobile Calendar Day Agenda with Hour Markers (Phase 10)**:
  - Container-width based mobile detection (< 480px) in `CalendarModule.tsx`: the day view renders a single-column hour-marker timeline (07:00 – 22:00) instead of the desktop list.
  - Empty hour slots act as one-tap quick-create targets: tapping opens the new Quick-Create Bottom Sheet with date and hour pre-filled.
  - Events render as touch cards with category accent bar, live clock time, location line and detail modal hand-off.
- **Quick Appointment Creation Bottom Sheet (Phase 10)**:
  - Mobile-only bottom sheet form reusing the desktop modal state engine (`prepareNewEventStates`, `handleCreateEventSubmit`) for identical Google Calendar / local database behavior.
  - Touch-optimized controls: min 44px inputs, quick duration chips (15m/30m/45m/1h/2h/All-day), category and storage destination selectors, sticky drag handle.
  - Floating quick-add action button (FAB) plus a next-upcoming-event quick bar (today's next event, fallback to next future date) in mobile day view.
- **Mobile Support Time-Tracking Widget & Ticket Cards (Phase 11)**:
  - `SupportServicesModule.tsx` list view now renders a compact dark time-tracking widget in mobile windows: live running timer with pulse animation, total booked hours of filtered tickets, and one-tap jump to the active ticket's timesheet.
  - Ticket table is replaced by a touch card stack below 640px container width: ticket number, priority star, status badge, customer/team line, booked hours, live timer chip and quick edit/delete actions.
  - Header actions (New Ticket, Mobile Sync) collapse to icon-only buttons on narrow screens.
- **Localization**: All new mobile calendar and support surfaces fully translated across German, English, French, and Spanish in `src/lib/i18n.ts` (including `calendar.event_singular`, `calendar.quick_add` re-use, `support.mobile_time_widget`, etc.).

## Version 24.0.0 — Mobile-Window Responsive Layout & Adaptive UI System
- **Mobile-Window Responsive System**:
  - Engineered adaptive window container architecture that responds dynamically to window resizing, narrow viewports (< 640px / < 480px), and mobile screen previews.
  - Automatically transitions horizontal desktop grid views and wide multi-column tables into compact vertical touch cards and thumb-friendly actions.
- **Mobile-Optimized Login, Lock Screen & Onboarding**:
  - Redesigned the Windows 11 lock screen for mobile and narrow window dimensions with responsive clock font sizing, refined date headers, and vertical swipe-up gestures.
  - Eliminated on-screen soft keyboard overlapping: converted the login viewport into a fluid `min-h-[100dvh]` scroll container so the "Forgot password?" link and user account switcher never collide when the mobile keyboard slides up.
  - Redesigned user account selector with a fluid responsive grid, touch-friendly 48px avatar targets, and full-width mobile card layout.
  - Prevented 920px minimum window width clamp on mobile: windows automatically adapt to 100% viewport width and height on mobile screens (< 768px).
  - Streamlined first-run account setup dialog with full-width responsive controls, touch-friendly password visibility toggles, and thumb-friendly step navigation.
- **Adaptive Contrast & Glow Harmony**:
  - Retained strict anti-clash contrast pairing and subtle border glow effects across all mobile viewports.
