SOCDOF Custom Flags Directory
==============================
Directory: public/languages/flags/

You can place custom flag images here for any language:
- Filename format: <language_code>.png, <language_code>.jpg, <language_code>.webp, or <language_code>.svg
  Examples:
  - en.png  (Custom flag image for English)
  - de.png  (Custom flag image for German)
  - it.png  (Custom flag image for Italian)
  - custom_pack.png (Custom flag for a custom language file)

Fallback behavior:
- If no custom image is found in this folder, SOCDOF uses standard crisp flag emojis (🇺🇸, 🇩🇪, 🇫🇷, 🇪🇸, etc.).
- For unknown custom packs without a flag, SOCDOF displays the standard black flag with a question mark (?).
