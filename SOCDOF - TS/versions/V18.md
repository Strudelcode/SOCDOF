## Key features

- **Multi-window desktop workspace:** Windows 11-style floating windows with Aero Snap, title-bar controls, taskbar minimization, maximization, and z-index management.
- **DIN 5008 and modern invoicing:** Professional invoice creation, fold marks, dynamic QR GiroCode payment generation, and high-resolution PDF export.
- **Touch-friendly POS and kitchen display:** Point-of-sale functionality with barcode scanner support, rapid item search, receipt printing, and KDS support.
- **Double-entry inventory and stock movements:** Real-time stock movement tracking, incoming goods, and inventory valuation.
- **Native installer support:** Electron and NSIS packaging for standalone offline Windows execution.
- **Theme customization:** Dynamic accent colors with real-time CSS variable binding in dark and light modes.

## v18.3.5 — 2026-08-24

- **More robust Windows setup assistant:** `.cmd`, `.bat`, and `.ps1` scripts use atomic Base64-encoded UTF-16LE PowerShell execution and open a native `FolderBrowserDialog`.
- **Automatic Windows directory structure:** Creates `Data`, `Backups`, `Exports`, and `Config`, together with a start script and desktop shortcut.
- **Simplified setup modal:** Removed unnecessary tabs and introduced a focused three-step flow with direct `.cmd`, `.bat`, and `.ps1` downloads.
- **Offline and GitHub Pages fix:** Relative Vite and asset paths support GitHub Pages subdirectories and opening the built `index.html` locally.
- **Automated Windows release workflow:** GitHub Actions creates NSIS installers and portable `.exe` builds for tags or manual workflow runs.

## v18.3.4 — 2026-08-24

- **Windows installation assistant:** Added interactive path selection, the standard directory structure, a desktop shortcut, and a local start script.
- **Local operation:** Removed the dependency on sandbox cloud URLs so the application can run offline.
- **Storage paths:** Backup and local data paths can be configured in Settings.
- **GitHub Releases:** Added direct links to prebuilt Electron and NSIS packages.

## v18.3.3 — 2026-08-24

- **Windows desktop focus:** Removed the legacy web fullscreen mode and top switch banners; the application starts directly in desktop mode.
- **Language selection:** Added a simplified, high-contrast dialog with English as the default language and SVG flags.
- **Centralized version management:** Synchronized version information across Settings, Documentation, README, and status documentation.
- **Documentation:** Added an interactive version history to the integrated manual.

## v18.3.2 — 2026-08-24

- **Calendar status:** Google/iCal status remains inactive until an actual connection is established.
- **Integrations:** Added links to the GitHub repository and Discord support at central locations.
- **Branding:** Added the SOCDOF logo as favicon, PWA icon, Start button, and dashboard header.
- **Company profile:** Updated the default company name to “Strudel's Test GmbH”.

## v18.3.1 — 2026-08-24

- **Windows launcher:** Added automatic generation of `.bat` and `.ps1` launchers.
- **Sound feedback:** Added sound feedback with a mute option.
- **Themes:** Added dark mode and DIN-compliant light mode with dynamic accent colors.

## v18.3.0 — 2026-08-20

- **Windows desktop core:** Added a multi-window manager with taskbar, Start menu, and window snapping.
- **Finance and invoicing:** Added BWA, EÜR, UStVA, and DIN 5008 invoice generation.
- **IndexedDB:** Added offline data storage with Dexie.js and JSON import/export.
