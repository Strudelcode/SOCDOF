# SOCDOF 0.30.0

- Performance: the contact and invoice lists only lay out the visible rows, so 50k contacts and
  100k invoices stay far below the 60 fps frame budget (measured: 0.10 ms and 0.20 ms median).
- Faster imports: invoice full-text indexing uses a rowid map (schema v9), which removed a
  quadratic write path — 100k invoices now import in seconds instead of minutes.
- Mobile companion sync: pair by QR code, upload tickets, times, expenses and kilometres from the
  phone, read them in the desktop.
- Print: DIN 5008 form B with fold and hole marks, multi-page position tables with repeated headers,
  and an ISO/IEC 18004 QR code on the invoice.
- Documents: real OOXML `.docx` export of invoices, plus reading foreign `.docx` templates.
- Backups: one service for the own `.socdofbak` container and the legacy `*.socdof.json`
  documents — inspect, list, restore either, with atomic restore.
